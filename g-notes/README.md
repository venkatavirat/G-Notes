# G-NOTES

G-NOTES is a modern note-taking application built with React. It provides users with a clean and intuitive interface to create, manage, and organize their notes efficiently. The application is designed with a focus on user experience and aesthetics, utilizing modern design principles to ensure a professional look and feel.

## Features

- **Responsive Design**: The application adapts seamlessly across mobile, tablet, and desktop viewports.
- **Sticky Navigation**: A user-friendly sticky top navbar that includes the brand logo, user avatar, and action buttons for easy access.
- **Modern Card UI**: Notes are displayed in stylish cards with rounded corners, smooth hover effects, and soft drop shadows, enhancing the visual appeal.
- **Subject Badges**: Tags for subjects are styled as colorful, rounded inline chips, making it easy to categorize and identify notes.

## Technologies Used

- React
- Vite
- CSS Modules
- Axios for API requests

## Installation

To get started with G-NOTES, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/g-notes.git
   ```

2. Navigate to the project directory:
   ```
   cd g-notes
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```

5. Open your browser and go to `http://localhost:3000` to view the application.

## Usage

Once the application is running, you can create, edit, and delete notes. Use the navigation bar to access different features and manage your notes effectively.
